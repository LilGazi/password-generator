# Password Generator 🔐

A beginner-friendly Python password generator that creates random passwords based on a user-defined length.

## Features

- 🔢 Custom password length
- 🔤 Uppercase and lowercase letters
- 🔢 Numbers
- 🔄 Generate multiple passwords in one session
- 🎲 Random character selection

## Technologies Used

- Python
- `random` module
- `string` module

## How It Works

The program asks the user to enter the desired password length. It then randomly selects characters from a combination of letters and numbers to create the password.

The user can also choose whether to generate another password or exit the program.

## How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:
